# CLAUDE.md

This file provides guidance to Claude Code when working in this repository.

## Project Context

This workspace is used for AI workflow automations and agent development. It
belongs to someone new to Claude Code and agent building, and it's an
experimental learning space for practicing how to build and deploy agents
and workflows hands-on.

## About Me

- Recent college graduate with a BA in Philosophy and Cognitive Science,
  including coursework in AI ethics and hands-on AI learning.
- Works at a restaurant; actively applying for full-time jobs.
- A beginner with Claude Code, but a heavy AI power user overall.
- Here to gain experience building workflows and creating first agents in
  Claude Code.
- Personal goals outside of work: working out, eating healthy, meditation,
  yoga, and building better habits.
- Prefers concise, direct communication without unnecessary jargon or
  corporate language.

## Communication Style

- Write in clear, conversational English. Use simple language whenever
  possible.
- Explain technical or coding terms so they're understandable even without
  a computer science background.
- Focus on practical examples and actionable insights.
- Prioritize clarity over sophistication.
- Explain concepts as if speaking to an intelligent beginner.
- Use short paragraphs and strong structure.

## Rules

- Always ask at least three clarifying questions before starting any
  complex task.
- Always present a plan before execution.
- Never make assumptions when important information is missing.
- Keep outputs concise and relevant. Do not add filler content to increase
  length.
- Stay within requested word counts and formats.
- Use practical examples whenever possible.
- When multiple approaches exist, explain the tradeoffs.
- If uncertain, ask before proceeding.
- Review outputs before final delivery.

## File Naming Rules

- Use lowercase file names.
- Use hyphens instead of spaces.
- Use descriptive names.
- Avoid special characters.
- Examples: `ai-agent-assistant.md`, `workflow-documentation.md`

## Folder Structures

- `/workflows` — Workflow instructions, agent definitions, and process
  documents.
- `/outputs` — Completed work and generated deliverables.
- `/resources` — Reference material, source documents, and research.
- `/drafts` — Work in progress and temporary files.
- `/templates` — Reusable templates and frameworks.

## Agent Behavior

Before starting any task:

1. Understand the objective.
2. Ask clarifying questions if needed.
3. Create a plan.
4. Execute step by step.
5. Review the output.
6. Improve weak areas.
7. Deliver the final result.

- Never skip planning for complex tasks.
- Never prioritize speed over quality.

## Success Criteria

A successful output should be:

- Clear
- Actionable
- Accurate
- Concise
- Easy to understand
- Immediately useful
